# Sống Khỏe — Cẩm nang sức khỏe cộng đồng

Trang chủ tiếng Việt cung cấp thông tin cơ bản về phòng sốt rét, sơ cứu và cách liên hệ cấp cứu. Trang dùng HTML, CSS và JavaScript thuần, không cần build, backend hay thư viện bên ngoài.

## Chạy thử

Mở `index.html` trực tiếp trong trình duyệt hoặc chạy một máy chủ tĩnh từ thư mục dự án, ví dụ:

```sh
python3 -m http.server 8000
```

Sau đó truy cập `http://localhost:8000`.

## Triển khai trên GitHub Pages

1. Đẩy các tệp lên nhánh `main`.
2. Trong repository, mở **Settings → Pages**.
3. Ở phần **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main`, thư mục `/(root)`, rồi lưu.

GitHub Pages sẽ dùng `index.html` làm trang chủ. Không cần quy trình build.

## Lưu ý sức khỏe

Nội dung chỉ nhằm mục đích giáo dục cộng đồng, không thay thế chẩn đoán, điều trị hoặc đào tạo sơ cứu. Trong tình huống khẩn cấp tại Việt Nam, gọi **115** và làm theo hướng dẫn của tổng đài. Tham khảo thêm các nguồn WHO, NHS và Red Cross được liên kết ở cuối trang.
